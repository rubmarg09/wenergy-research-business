Foix is where Wenergy moves from product architecture to real-world proof.

The pilot is designed to test whether Wenergy can transform a large, multi-energy territorial screening universe into a small, evidence-backed pipeline of projects that deserve professional investigation.

The Pilot Question

Across selected local renewable and recoverable-energy pathways, which candidate relationships within Foix-Varilhes deserve professional investigation first — and why?

Territory

A real place — not a synthetic test environment.

Foix combines a compact urban centre, surrounding rural communes, public buildings, businesses, agricultural activity, environmental constraints and varied renewable/recoverable-energy pathways.

The Funnel

Reduce complexity intelligently.

The value of the pilot lies in reducing a massive possibility space into a defensible professional investigation pipeline.

~100 — Stronger Algorithmic / Evidence Longlist Workflow design target
~30–50 — Deeper Human Review Territorial + evidence review

~5–15 — Professional Investigation Qualified handoff pipeline
Only the 32,628 current screening count is an observed POC output. Later funnel volumes are pilot workflow targets, not guaranteed outcomes.
Pilot Deliverables

The output is a decision package — not another static report.

01 Opportunity Overview Multi-energy territorial screening.

03 Project Lens Review Deeper human analysis.

08 Constraint Context Planning/environmental review needs.

10 Value Report What changed in the decision workflow.
Indicative Pilot Timeline

Pilot Validation

Success means changing a real decision workflow.

≥90% Evidence traceability target.
100% Shortlisted Project Lenses with clear next action.
≥4/5 Territory usefulness target.
≥4/5 Expert usefulness target.
≥1 Real decision changed, accelerated or deprioritised.
Paid? Willingness to pay / conversion evidence.
TECHNICAL FUNCTIONALITY IS NECESSARY. REAL DECISION VALUE IS THE ACTUAL PILOT TEST.

Decision Board

A strong pilot can recommend not proceeding.

ADVANCE Professional investigation justified.
VALIDATE DATA FIRST Potential exists, but evidence gap is material.
MONITOR Not yet a priority.
DEPRIORITISE Lower relative investigation value.
REJECT AT SCREENING Relationship currently too weak.
“DO NOT BUILD” CAN BE A SUCCESSFUL PRODUCT OUTCOME. Avoiding unnecessary studies can save money, professional capacity and stakeholder time.

PROVE LOCALLY → REPEAT REGIONALLY → STANDARDISE NATIONALLY
THE FOIX PILOT IS NOT DESIGNED TO PROVE THAT WENERGY CAN FIND OPPORTUNITIES. The POC already does that. The pilot must prove that Wenergy can help real users decide which opportunities deserve attention, connect them to professional action and create enough value to justify payment.
