Product Architecture

One system — several intelligence layers.

Wenergy separates raw evidence, actor context, project logic and user-facing action so every output remains explainable.

01 — Data / Energy Fabric
Territorial datasets, buildings, energy context, environmental and planning layers, infrastructure and pathway-specific evidence.
02 — Actor Layer
Municipalities, facilities, businesses, farmers, operators, residents, experts and other actors linked to project relationships.
03 — Wenergy Engine
Deterministic screening, matching, evidence classification, context enrichment, ranking and data-gap logic.
04 — Opportunities
Candidate renewable and recoverable-energy relationships across multiple pathways.
05 — Project Lens
Structured project object containing evidence, actors, constraints, uncertainty, maturity and next actions.
06 — Map / UI / Action
Territorial exploration, decision support, engagement, professional handoff and project follow-up.
